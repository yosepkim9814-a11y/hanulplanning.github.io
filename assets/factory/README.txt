HANUL PLANNING factory image naming guide
=========================================

The redesigned factory page uses the following filenames inside /assets/factory/ :

- hanul-overview.png
- hanul-line-01.png
- etb-overview.png
- etb-factory-01.jpg
- etb-line-01.jpg
- kimsun-overview.png
- kimsun-factory-01.jpg
- kimsun-line-01.jpg
- kimsun-factory-02.jpg
- kimsun-line-02.jpg

Recommended replacement rule:
- Keep the same filename when replacing with higher-resolution originals.
- Use landscape images when possible for overview/factory/line shots.
- JPG is recommended for photos, PNG for overview slides or graphic layouts.

Current mapping:
- HANUL: overview slide + woven facility collage
- ETB: overview slide + gate photo + line photo
- KIMSUN: overview slide + 4 factory/line photos
